Where the X-rays come from

The panel on polymarket.com reads its X-rays from the CALIBRE site. You do not need to change anything: it already points at the live site.

Default: https://calibre-blush.vercel.app. Developers running the site locally can use http://localhost:3000.

The extension asks for one permission, storage, for this setting. It runs only on polymarket.com, reads only the page address, and sends the wallet, username or market from that address to the site above.
